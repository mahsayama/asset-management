# Asset Management - Context Memory

## Project Info
- **Name**: Asset Management System
- **Type**: IT Asset Management Application
- **Framework**: CodeIgniter 3.1.13
- **Language**: PHP >= 7.4
- **Database**: PostgreSQL 15 (production/staging via Docker) & SQLite fallback (db.sqlite3)
- **Backup**: backup_asset.sql (MySQL format)
- **Containerization**: Docker (dockerfile + docker-compose.yml)
- **Extra Libraries**: PhpSpreadsheet ^1.29 (Excel export/import)

## Tech Stack

### Backend
- PHP >= 7.4
- CodeIgniter 3.1.13 (MVC framework)
- Composer (dependency manager)

### Frontend
- Bootstrap 5.3.0 (CSS framework)
- Bootstrap Icons 1.11.3
- HTMX 1.9.10 (interaktivitas tanpa full page reload)
- Chart.js (dashboard charts/grafik)
- Tom Select 2.3.1 (searchable dropdown)
- Google Fonts - Inter (font family)
- Custom CSS (sidebar, sticky header, htmx indicator, dll.)

### Database
- PostgreSQL 15 (primary, via Docker)
- SQLite (fallback untuk local dev tanpa PostgreSQL extension)

### DevOps & Infra
- Docker (PHP 7.4 + Apache image)
- Docker Compose 3.8 (web + postgres services)
- Apache dengan mod_rewrite (clean URLs)
- GitLab CI/CD (4 stages: build, test, deploy staging, deploy production)
- GitLab Container Registry (Docker image storage)
- SSH-based deployment ke server

### Deployment
- Staging: auto-deploy via CI/CD, port 8080
- Production: manual trigger via CI/CD, port 80

## Key Directories
- `application/` - Main CI3 application
  - `config/` - Configuration files (database.php, routes, autoload, dll.)
  - `controllers/` - Controllers (MVC)
  - `models/` - Models (MVC)
  - `views/` - Views (MVC)
    - `templates/` - header.php, footer.php, sidebar.php (layout utama)
    - `auth/` - Login/register views
    - `dashboard/` - Dashboard views
    - `inventory/` - Asset inventory views
    - `reports/` - Report views
    - `settings/` - Settings views
    - `errors/` - Error pages
  - `helpers/` - Helper functions
  - `logs/` - Application logs
- `vendor/` - Composer dependencies
- `DOCUMENTATION/` - Project documentation
- `.vscode/` - VS Code settings

## Key Files
- `index.php` - Entry point (CI3 bootstrap)
- `.env` / `.env.example` - Environment config
- `docker-compose.yml` - Docker setup (web + postgres)
- `dockerfile` - Docker build config (PHP 7.4 Apache)
- `.gitlab-ci.yml` - CI/CD pipeline (build, test, deploy staging, deploy production)
- `setup.sh` - Setup script
- `walkthrough.md` - Walkthrough guide
- `composer.json` - PHP dependencies
- `db.sqlite3` - SQLite database (local dev)

## Database Config
- Config file: `application/config/database.php`
- Supports dual DB: PostgreSQL (production) & SQLite (local fallback)
- Reads from env vars first, then `.env` file
- Auto-fallback to SQLite if pgsql extension not loaded
